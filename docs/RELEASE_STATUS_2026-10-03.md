## Mobile graphics and installation

- The Android package is `com.fishingfree.game`, min API 24, version 1.0.16 / version code 17. Its current launcher opens the hosted PWA in Chrome on Android 10 and newer; first launch requires internet.
- The full island renderer needs a usable WebGPU adapter. Chrome's `chrome://gpu` entry marked “hardware accelerated” does not guarantee `navigator.gpu.requestAdapter()` succeeds for the game.
- The published 1.0.16 APK/PWA still stops at the graphics diagnostics screen. Local version 1.0.19 offers an optional Scenic Fishing mode after a failed WebGPU startup: it uses six in-game 3D scene captures with slow camera motion and keeps fishing, collection and progression playable. This is a scenic touch mode, not full realtime 3D; it is not yet deployed to Pages or GitHub Actions.
- The owner has reported an Android 10 Huawei ELE-L29 and identified a Samsung Galaxy A52 on Android 12 or newer. Neither physical phone has been verified with this exact APK. Android 10 WebGPU is best-effort; the A52 is the first target for a 3D device check.

A free Apple ID can be used for personal Xcode testing from a Mac, but that path requires a Mac and connected iPhone; the GitHub Simulator build is not an iPhone install package.
